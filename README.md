# Zen Waves

Zen Waves is a small static relaxation sound mixer. Open `index.html`, press play, and blend the ambient sound sliders.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload the full folder contents, including `index.html`, `css`, `javascript`, `images`, and `sounds`.
3. In the repository, go to **Settings > Pages**.
4. Set the source to the `main` branch and `/root`, then save.

Because this is a static site, no build step or package install is needed.

## Local Preview

Open `index.html` directly in a browser, or serve the folder with any static file server.
