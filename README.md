# Zen Waves

Zen Waves is a calming ambient sound mixer built with HTML, CSS, and JavaScript. It lets you create a relaxing background soundscape by blending nature sounds with simple volume sliders and changing the visual background.

## Live Demo

[Open Zen Waves](https://deepanbiswas07.github.io/Zen-Waves/)

## Features

- Mix multiple ambient sounds independently
- Control the master volume
- Play, pause, mute, and reset the soundscape
- Change the background image
- Static frontend with no build step or backend required

## Sounds Included

- Birds
- Rain
- Waves
- Thunder
- Water
- Wind chimes
- Forest
- Wind
- Fire

## Tech Stack

- HTML
- CSS
- JavaScript
- GitHub Pages

## Run Locally

Open `index.html` in a browser.

No installation, build command, or server is required.
